# Purah

A small native Mac editor for JSON, Markdown, and text files.

[Website](https://iamjason.github.io/purah-site/) · [Releases](https://github.com/iamjason/purah-site/releases) · [Report an issue](https://github.com/iamjason/purah-site/issues)

Open each file exactly as written, format JSON only when requested, and show an optional Markdown preview. Purah uses native document windows, file dialogs, Undo/Redo, and Find. Files stay on your Mac.

Requires macOS 15 or later. Universal builds support Apple silicon and Intel. Supports UTF-8 and BOM-marked UTF-16 text files up to 2 MB.

This public repository hosts the website and artwork. Future public app releases will be published here. Application source is maintained separately.

The first public app download is being prepared. No release package is published yet.

## Hyrule Compendium

The `hyrule.json` manifest and `hyrule-tool` repository topic register Purah with the [Compendium](https://iamjason.github.io/hyrule-compendium-site/).

The site is served by GitHub Pages from `main:/`. No build step or runtime dependencies are required.
